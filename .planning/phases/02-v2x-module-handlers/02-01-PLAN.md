<objective>
Fix the SmartCharging module to accept V2X bidirectional power transfer (BPT) charging needs and generate discharge-aware ChargingProfiles.

Purpose: The existing NotifyEVChargingNeeds handler rejects V2X requests because (1) validation only checks for AC/DC parameters (not v2xChargingParameters), and (2) the profile calculator throws on BPT energy transfer modes. This blocks the entire V2X discharge flow.

Output: SmartCharging module accepts BPT modes (AC_BPT, DC_BPT, AC_BPT_DER, DC_ACDP_BPT), reads V2X parameters, and generates profiles with dischargeLimit fields.
</objective>
