<objective>
Add the fourth Hubject env-var passthrough (BASEURL) to `Server/docker-compose.yml` and `Server/.env.example`, completing the set started by quick task 260429-ixg (CLIENTID, CLIENTSECRET, TOKENURL). The Hubject client (`02_Util/src/certificate/client/hubject.ts:227-241`) sends `audience: this._baseUrl` in the OAuth2 client_credentials request — operators on non-test Hubject envs (US QA `https://us.plugncharge-qa.hubject.com`, EU QA, prod) need to override the config.json default (`https://open.plugncharge-test.hubject.com`) or they hit `403 access_denied: Service not enabled within domain`.

Purpose: Close the env-var override gap missed by 260429-ixg. Compose does not auto-inject `.env` values into containers — vars must be explicitly listed in `environment:` to reach the running process. Without this passthrough, the `BASEURL=...` line in an operator's `Server/.env` is silently ignored, the config.json default wins, and OAuth2 fails with a misleading 403.

Output: Two file edits. One new line in `Server/docker-compose.yml` `citrine.environment` block (alphabetically before CLIENTID). One new placeholder + comment block in `Server/.env.example` (alphabetically first of the four Hubject keys).
</objective>
