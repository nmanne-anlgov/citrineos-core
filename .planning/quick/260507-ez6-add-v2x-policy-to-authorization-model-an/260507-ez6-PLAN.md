<objective>
Add a per-Authorization V2X energy-transfer policy and surface a manual override in the BPT Console.

Purpose: Today the CSMS hardcodes `allowedEnergyTransfer: ['DC']` everywhere — both in the Authorize response and on transaction Start. This blocks per-token policy decisions (e.g. "this driver may discharge, that one may not") and prevents an operator from toggling V2X on a live session for testing. This task moves the policy onto the `Authorization` row, threads it through Authorize and TransactionEvent.Started, and adds a console-side toggle that fires `NotifyAllowedEnergyTransfer` mid-session.

Output:

- New `allowedEnergyTransfer` column on `Authorizations` (model + DTO + migration + Hasura)
- `_handleAuthorize` and the TransactionsModule Started handler read the column instead of hardcoding
- New auto-eMAID rows default to `['DC', 'DC_BPT']` so first-time eMAID drivers can discharge
- BPT Console gets an Allow V2X / Revoke V2X toggle on the active transaction panel
  </objective>
